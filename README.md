## 🚀 Cómo ejecutarla en tu ordenador

Necesitas tener instalado [Node.js](https://nodejs.org/) (versión LTS) y Git.

**1. Clona el repositorio**

```bash
git clone https://github.com/juanik085/GUSANOH-rock-band.git
```

**2. Entra en la carpeta e instala las dependencias**

```bash
cd GUSANOH-rock-band
npm install
```

**3. Arranca el servidor de desarrollo**

```bash
npm run dev
```

Abre la dirección que aparezca en la terminal (normalmente `http://localhost:5173`).

**4. Genera la versión final**

```bash
npm run build
```
