# GUSANOH

Web oficial de **GUSANOH**, grupo de rock alternativo de Mazarrón (Murcia).

🌐 **Web en directo:** https://gusanoh.netlify.app

## Qué incluye

- Inicio con el logo de la banda
- Música con reproductor
- Directos
- La banda
- Galería con lightbox
- Contacto

## Tecnologías

- HTML, CSS y JavaScript
- [Vite](https://vitejs.dev/) como herramienta de desarrollo
- Desplegada en Netlify

## Cómo ejecutarla en tu ordenador

1. Clona el repositorio:
   ```
   git clone https://github.com/juanik085/GUSANOH-rock-band.git
   ```
2. Entra en la carpeta e instala las dependencias:
   ```
   cd GUSANOH-rock-band
   npm install
   ```
3. Arranca el servidor de desarrollo:
   ```
   npm run dev
   ```
4. Para generar la versión final:
   ```
   npm run build
   ```
